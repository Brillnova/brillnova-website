PLANNED PILOT HARDWARE

BN-USV carrier boards

A planned Main-and-Sub carrier-board set for the modular BN-USV V2 architecture.

Not for sale yet · Interest registration open

What the set is intended to do

Main carrier board

Planned as the central I/O board for the Main module, bringing together sensor, RC receiver, battery-sense and CAN connections.

Matching Sub carrier board

Planned for each propulsion module, with CAN, ESC/PWM and Sub-battery connection points. The same board concept supports the left and right sides.

Serviceable integration

Clear connector silkscreen, documented wiring and modular replacement are design goals for a future pilot batch.

Prototype statusConnector placement, CAN termination, sensor labels and enclosure fit are still being revised and verified. Specifications on this page are not final.
